# LIEN ブランド封筒 ＆ ロゴ デザイン

株式会社LIEN 様の **角2号・長形3号封筒** のデザイン案一式です。
**ご支給の実ロゴ（LIEN CONSTRUCTION）** を使用し、ネイビー基調で **6コンセプト**
ご用意しています。

> **本制作の方向性**: **Concept B（フッターバンド）** を採用。
> 仕上げ提示 `preview/conceptB-final.png`、Word版 `word/lien-envelopes.docx`。

---

## 1. 封筒デザイン 6コンセプト

実ロゴは上部に配置し、差出人情報は封筒**下部**にまとめています（A/B/C/E）。
D は中央、F は左パネル下部に差出人を配置。

| 案 | 名称 | 特徴 |
|----|------|------|
| **A** | ミニマル・ライン | 余白を活かした上品な構成。細いネイビーのラインの下に差出人情報。控えめで知的。 |
| **B** | フッターバンド（採用） | 下部の濃紺バンド＋左の縦ラインでL字フレーム。左にロゴ／右にQR、中央に差出人情報。上に「在中」チェック欄。宛名はラベル貼付。 |
| **C** | アーキテクチャル・スパイン | 左の柱＋下の帯で「L字」を構成。建設業らしい構造感。 |
| **D** | センタード | ロゴ・差出人を中央に。短いネイビー罫で締めた左右対称の端正なレイアウト。 |
| **E** | フレーム | ネイビーのキーライン枠＋内側スチール罫。きちんとしたレターセット風。 |
| **F** | サイドバー | 左の濃紺カラーブロックに差出人を白文字で。非対称でモダンな色面構成。 |

プレビュー（宛名スペースのガイド入り）:

- `preview/kaku2-concepts.png` … 角2号 全6案
- `preview/chokei3-concepts.png` … 長形3号 全6案
- `preview/other-concepts.png` … 追加案 D/E/F（両サイズ）
- `preview/conceptB-final.png` … 採用案 B

> 宛名・〒・切手枠のグレー文字は**配置確認用のガイド**で、実際には印刷されません。
> 印刷マスター（`.svg`）には差出人ブランド要素のみが含まれます。

### サイズ
- **角2号**: 240 × 332 mm（A4を折らずに入る）
- **長形3号**: 120 × 235 mm（A4三つ折り用）
- 向きは添付書式に合わせ縦置き。横置き版が必要な場合は調整可能です。

## 2. ロゴ

ご支給いただいた**実ロゴ（メタリックの LIEN CONSTRUCTION）** をそのまま使用します。

| ファイル | 内容 |
|----------|------|
| `logo/lien-master.png` | 実ロゴ（**透過背景**・余白トリム済み／`public/lien_logo_master.png` を加工） |

- 封筒では**上部の白地に大きく配置**します。メタリックの質感は濃い色のため、
  下部の濃紺バンドに重ねると沈むので、白地側に置く構成にしています。
- 各封筒の `.svg` には、このロゴを**埋め込み済み**（リンク切れの心配なし）。
- 単色（墨1色）印刷や FAX・スタンプ等でメタリックが再現できない用途向けに、
  **同ロゴの1色ベクター版**が必要であれば別途お作りできます。

## 3. カラー & 書体

| 役割 | 色 | HEX | 印刷の目安 |
|------|----|-----|-----------|
| 主色／アクセント | ネイビー | `#223A5C` | C90 M75 Y40 K30 前後の濃紺。フッターバンド・罫線 |
| キューブ濃面 | ディープネイビー | `#19293F` | 立体の最暗面 |
| キューブ中面 | スチールネイビー | `#3C5275` | 立体の中間面 |
| ハイライト／細線 | ライトスチール | `#C7D0DC` | 帯上の極細ライン |
| 文字（黒） | 墨黒 | `#16181D` | K100 もしくはリッチブラック |
| 用紙 | 温かみのある白 | `#FAF9F5` | ナチュラル系の封筒用紙を想定 |

> 配色はネイビー基調。ロゴは支給データ（メタリック）をそのまま使用しています。

- 和文（社名・住所）プレビューは IPA ゴシック。最終データでは
  **游ゴシック / Noto Sans JP / ヒラギノ角ゴ** など本文用ゴシックを推奨。
- 欧文・数字（TEL/FAX）は Helvetica / Arial 系。

## 4. 入稿データ（フチなし＝印刷会社用）

家庭/オフィス機は用紙端まで印刷できず必ず余白が残ります。**完全にフチなし**で
仕上げるには、下記の入稿用PDF（**塗り足し3mm込み**）を印刷会社（ネット印刷等）へ：

- `print/LIEN封筒_角2号_入稿.pdf` … ページ 246×338mm（仕上がり 240×332mm＋塗り足し3mm）
- `print/LIEN封筒_長形3号_入稿.pdf` … ページ 126×241mm（仕上がり 120×235mm＋塗り足し3mm）

- ベクター原版は `envelopes/kaku2-B-band.svg` / `chokei3-B-band.svg`（塗り足し3mm込み）。
  Illustrator等で開けば EPS/AI/PDF へ書き出せます（ロゴ・QRは埋め込み済み）。
- 帯・縦ラインは断ち落とし（フチなし）想定で塗り足しを付けています。

## 5. Word 版（採用案 B・サイズ別）

- `word/LIEN封筒_角2号.docx` … 角2号（240×332mm）
- `word/LIEN封筒_長形3号.docx` … 長形3号（120×235mm）

- 各ファイルは封筒原寸の1ページ・**余白0**で、デザインを**フチまでフルブリード**配置。
- ロゴ・QR・濃紺バンドは**透過PNG**なので、封筒の地に直接刷れます（宛名欄は無し）。
- 仕上がりイメージ: `preview/word-result-kaku2.png` / `preview/word-result-chokei3.png`
- 端まで刷るには**フチなし印刷**（または「実際のサイズ／100%」）を選んでください。
  ご家庭/オフィス機でフチなし不可の場合は、§4 の SVG/PDF を印刷会社へ入稿が確実です。

## 7. 再生成・編集方法

デザインはコードから生成しています（数値・色の調整が容易）。

```bash
cd design/generator
npm install @resvg/resvg-js   # PNGプレビュー生成に必要

node build.cjs                # envelopes/ preview/ を再生成（全6案）
node render-word-bg.cjs       # word/bg-*.png（Word背景・透過）を生成
python3 build-word.py         # word/LIEN封筒_角2号.docx・_長形3号.docx を生成
node render-word-preview.cjs  # preview/word-result-*.png を生成
```

- `brand.cjs` … 配色（ネイビー）と共通ヘルパー
- `envelopes.cjs` … 封筒6コンセプトのレイアウト・差出人情報・ロゴ埋め込み
- `build.cjs` … 封筒/プレビューの一括書き出し
- `build-word.py` … Word（.docx）組み立て（依存ライブラリなし）
- ロゴ画像は `logo/lien-master.png` を参照（差し替える場合はこのファイルを置換）

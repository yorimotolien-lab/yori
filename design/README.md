# LIEN ブランド封筒 ＆ ロゴ デザイン

株式会社LIEN 様の **角2号・長形3号封筒** のデザイン案一式です。
**ご支給の実ロゴ（LIEN CONSTRUCTION）** を使用し、差出人情報を封筒下部にまとめ、
3つのコンセプトでご用意しています。

> **本制作の方向性**: **Concept B（フッターバンド）＋ ネイビー基調** を採用。
> 仕上げ提示は `preview/conceptB-final.png` を参照してください。
> （他案・モノクロ等も同じネイビー配色で生成済みです）

---

## 1. 封筒デザイン 3コンセプト

差出人情報はすべて封筒**下部**に配置しています。

| 案 | 名称 | 特徴 |
|----|------|------|
| **A** | ミニマル・ライン | 余白を活かした上品な構成。細いネイビーのラインの下にロゴと差出人情報。控えめで知的な印象。 |
| **B** | フッターバンド（採用） | 下部に深いネイビーの帯。白抜きロゴ＋スチールの極細ライン。力強くモダンで視認性が高い。 |
| **C** | アーキテクチャル・スパイン | 左の柱＋下の帯で「L字」を構成。建設業らしい構造感とロゴの“L”が呼応する象徴的なデザイン。 |

プレビュー（宛名スペースのガイド入り）:

- `preview/kaku2-concepts.png` … 角2号 3案
- `preview/chokei3-concepts.png` … 長形3号 3案

> 宛名・〒・切手枠のグレー文字は**配置確認用のガイド**で、実際には印刷されません。
> 印刷マスター（`.svg`）には差出人ブランド要素のみが含まれます。

### サイズ
- **角2号**: 240 × 332 mm（A4を折らずに入る）
- **長形3号**: 120 × 235 mm（A4三つ折り用）
- 向きは添付書式に合わせ縦置き。横置き版が必要な場合は調整可能です。

## 2. ロゴ

ご支給いただいた**実ロゴ（メタリックの LIEN CONSTRUCTION）** をそのまま使用します。

| ファイル | 内容 |
|----------|------|
| `logo/lien-master.png` | 実ロゴ（**透過背景**・余白トリム済み／`public/lien_logo_master.png` を加工） |

- 封筒では**上部の白地に大きく配置**します。メタリックの質感は濃い色のため、
  下部の濃紺バンドに重ねると沈むので、白地側に置く構成にしています。
- 各封筒の `.svg` には、このロゴを**埋め込み済み**（リンク切れの心配なし）。
- 単色（墨1色）印刷や FAX・スタンプ等でメタリックが再現できない用途向けに、
  **同ロゴの1色ベクター版**が必要であれば別途お作りできます。

## 3. カラー & 書体

| 役割 | 色 | HEX | 印刷の目安 |
|------|----|-----|-----------|
| 主色／アクセント | ネイビー | `#223A5C` | C90 M75 Y40 K30 前後の濃紺。フッターバンド・罫線 |
| キューブ濃面 | ディープネイビー | `#19293F` | 立体の最暗面 |
| キューブ中面 | スチールネイビー | `#3C5275` | 立体の中間面 |
| ハイライト／細線 | ライトスチール | `#C7D0DC` | 帯上の極細ライン |
| 文字（黒） | 墨黒 | `#16181D` | K100 もしくはリッチブラック |
| 用紙 | 温かみのある白 | `#FAF9F5` | ナチュラル系の封筒用紙を想定 |

> 配色はネイビー基調。ロゴは支給データ（メタリック）をそのまま使用しています。

- 和文（社名・住所）プレビューは IPA ゴシック。最終データでは
  **游ゴシック / Noto Sans JP / ヒラギノ角ゴ** など本文用ゴシックを推奨。
- 欧文・数字（TEL/FAX）は Helvetica / Arial 系。

## 4. 入稿データについて

- `envelopes/*.svg` が**印刷用マスター**です（**塗り足し3mm込み**、仕上がりは上表のサイズ）。
- 帯・スパインは断ち落とし（フチなし）想定で塗り足しを付けています。
- ロゴは各 `.svg` に**埋め込み済み**（PNG）なので、ファイル単体で完結します。
- SVGはベクターなので、Illustrator等で開いて **PDF / EPS / AI** に書き出し可能。
  印刷会社へはPDF入稿が一般的です。

## 6. 再生成・編集方法

デザインはコードから生成しています（数値・色の調整が容易）。

```bash
cd design/generator
npm install @resvg/resvg-js   # PNGプレビュー生成に必要
node build.cjs                # envelopes/ preview/ を再生成
# resvg未導入なら自動でPNGをスキップし、SVGのみ書き出します
```

- `brand.cjs` … 配色（ネイビー）と共通ヘルパー
- `envelopes.cjs` … 封筒3コンセプトのレイアウト・差出人情報・ロゴ埋め込み
- `build.cjs` … 一括書き出し
- ロゴ画像は `logo/lien-master.png` を参照（差し替える場合はこのファイルを置換）
